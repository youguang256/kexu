## 一、这是什么

一个 Android 课表 App。核心能力：

1. **教务课表自动导入**（不走手工复制粘贴）
2. 上课/课前提醒（系统闹钟，锁屏可响）
3. 作业与考试倒计时
4. 学习通（超星）作业/进度同步
5. 成绩汇总、桌面小组件、WebDAV 备份、多套课表、深/浅色、简繁英

技术栈刻意选了「零构建、零依赖」的组合：

| 层 | 技术 | 为什么 |
|---|---|---|
| UI | 原生 HTML/CSS/JS（无框架、无打包） | 改一行就能跑，不需要 npm/webpack |
| 外壳 | Android WebView（Java） | 需要系统闹钟 / 小组件 / 原生 HTTP |
| 数据 | localStorage | 单机自用，无后端 |
| 服务端（可选） | Node 单文件 `server.mjs` | 只做两件事：学习通代理、静态托管 |

## 三、数据模型（localStorage key = `coursepilot.v1`）

```js
{
  settings: {
    termName, termStart:'2026-09-07', termStartSet:true, totalWeeks:20,
    weekStart:1, theme:'dark'|'light', lang:'zh-CN'|'zh-TW'|'en',
    periods:[{no:1,start:'08:00',end:'09:40'}, ...],   // 学校是 5 大节
    preClassMinutes:15, classReminderOn, preClassReminderOn, deadlineAheadHours:24,
    ui:{ bg:'', cellHeight:62, radius:10, gap:2, opacity:1, blockFields:['name','location'] },
    webdav:{url,user,pass,dir}, wecom:{webhook,on,staleDays,lastSyncAt,lastPush},
    activeSheetId, proxyBase
  },
  courses: [   // ← 当前课表的实时副本
    { id, name, teacher, color, source,
      sessions:[ { weekday:1..7, startPeriod, endPeriod, location, weeks:[1,2,...] } ] }
  ],
  sheets: [ { id, name, periods:[...], courses:[...] } ],   // 多套课表
  todos: [ { id, courseName, title, due:'2026-11-26 23:59', kind, done, source } ],
  exams: [ { id, courseName, title, start, end, location, seat, note } ],
  grades:[ { id, courseName, credit, usual, final, total, gpa } ],
  cx:     { status, lastSync, courses:[], tasks:[] },       // 学习通快照
  notified:{}                                                // 防重复提醒
}
```

**关键约定**

- `periods` 是「大节」：学校课表上一格 = 2 小节课。5 大节即
  `08:00-09:40 / 10:00-11:40 / 14:00-15:40 / 16:00-17:40 / 19:00-20:40`
- `sessions[].weeks` 为空数组 = **每周都上**；有值 = 只在这些周出现
- `state.courses` 与 `state.sheets[active].courses` 是同一份数据，`S.saveActive()` 负责同步

## 四、教务抓取：两条链路（重点）

这个项目在教务上有**两套实现**，历史原因，都保留着：

### 链路 A：适配器运行时（当前默认入口）

`NativeBridge.eduLogin()` → `AdapterActivity`

```
WebView 打开 jw.csuse.edu.cn（用户自己登录：账号密码 / 企业微信 SSO 都行）
  ↓ 每个页面注入 adapters/bridge.js + adapters/csuse.js
  ↓ 适配脚本读 DOM / 调页面内接口
  ↓ 通过 window._shiguangNativeBridge.postMessage 回传
  ↓ AdapterActivity 收消息 → EduImportStore 转成本 App 数据 → 存 prefs → 关闭
前端 onResume → window.onEduLoginChanged() → Native.takeEduCourses() → 导入
```

**桥协议**（与拾光课表一致，`adapters/bridge.js` 有完整注释）：

| action | 用途 |
|---|---|
| `showToast` / `showAlert` / `showPrompt` / `showSingleSelection` | 原生弹窗 |
| `importCourse` | 交回课程（拾光 `ImportCourseJsonModel` 形状） |
| `setTimeSlots` | 交回作息 |
| `setCurrentWeek` / `setSemesterStart` | 学期信息 |
| `notifyTaskCompletion` | 抓完通知关闭 |

### 链路 B：H5 token + JSON 解析（`EduLoginActivity`）

新版教务是独立 SPA：`jwh5.csuse.edu.cn`，鉴权靠 **URL 里的 JWT**，存在 `sessionStorage`。

```
淘宝式流程：CAS/企业微信扫码 → 进 H5 → 读 token → 调接口
接口：POST /njwhd/Get_sjkbms                    取节次模式 kbjcmsid
      POST /njwhd/student/curriculum?xnxq01id=&kbjcmsid=xxx
返回：{ data:[ { item:[ { courseName, teacherName, location,
                        classTime:"10102", classWeek:"3,6-17" } ] } ] }
```

**字段含义（血泪教训，别猜）**

- `classTime` = `星期(1位) + 起始小节(2位) + 结束小节(2位)`，`"10102"` = 周一第 01-02 小节
- `classWeek` = 周次，`"3,6-17"`
- 小节 → 大节：`大节 = ⌈小节 ÷ 2⌉`
- ⚠️ 不要用 `weekNoteDetail`（`"101,102"`）当节次，它是另一种编码，按逗号切会错位
- ⚠️ `kkzc` 字段是 `null`，周次在 `classWeek`

## 五、原生层要点

### MainActivity —— 页面加载三级兜底

```
① file:///android_asset/www/index.html
② loadDataWithBaseURL（直接读 assets 文本）
③ https://appassets.androidhost/...（WebViewAssetLoader 拦截）
④ 都失败 → 显示「页面加载失败 + 版本号」，可点重试
```

> 教训：曾用 ①=虚拟域名，在某些 WebView 上 `shouldInterceptRequest` 没生效，
> 直接走 DNS 解析报 `ERR_NAME_NOT_RESOLVED`，白屏。

### NativeBridge —— JS 调原生的全部入口

| 方法 | 作用 |
|---|---|
| `schedule(json)` | 排系统闹钟（上课/课前/截止/考试） |
| `requestNotificationPermission()` | 通知权限 |
| `updateWidget(json)` | 推送今日课程给桌面小组件 |
| `addToCalendar(json)` | 写入系统日历（CalendarContract） |
| `eduLogin()` / `eduCookie()` / `eduLoggedIn()` / `eduLogout()` | 教务登录态 |
| `eduFetch(url,method,body)` | 带 Cookie 请求教务（绕 CORS） |
| `takeEduCourses()` | 取走刚抓到的课表（取完即清空） |
| `httpPost(url,json)` | 仅允许 `qyapi.weixin.qq.com`（企业微信机器人） |

### 提醒链路

```
JS buildAlarms() → Native.schedule() → Alarms.java（AlarmManager）
   → AlarmReceiver（发通知）→ BootReceiver（重启后重排）
```

### 小组件

```
JS pushWidget()（每次 render 时算今日剩余课程）
  → Native.updateWidget() → 存 prefs → CourseWidgetProvider.refresh()
  → RemoteViews 渲染 widget_course.xml
```

## 六、服务端 `server.mjs`（可选）

只在两种场景需要：手机上想用网页版、或学习通同步（浏览器有跨域）。

| 路由 | 作用 |
|---|---|
| `GET /` | 托管 `app/` |
| `GET /setup` | 粘贴学习通 Cookie 的页面 |
| `POST /api/cx/login` | 学习通手机号+密码登录（AES-128-CBC，key=`u2oh6Vu^HWe4_AES`） |
| `POST /api/cx/sync` | 拉课程/作业/进度 → 返回 App 能吃的快照 |
| `POST /api/edu/fetch` | 教务转发（仅白名单域名），Cookie 存 `secrets/jw-cookie.txt` |

> 该教务站会返回 `Cache‑Control`（U+2011 连字符），Node 内置 fetch 解析不了，
> 所以 `server.mjs` 一律用 `curl` 子进程发请求。

## 七、构建

```bash
bash build-apk.sh        # 需要 JDK17 + Android SDK，见脚本内路径
# 产物：coursepilot-debug.apk
```

构建前**必须**把前端拷进 assets（脚本已包含）：

```bash
rm -rf android/app/src/main/assets/www
cp -r app android/app/src/main/assets/www
```

> 教训：漏了这一步，APK 里跑的还是旧 JS，改了代码却「没生效」。

## 八、排错手册

| 现象 | 先看哪里 |
|---|---|
| 白屏 / 无法打开 | MainActivity 的三级兜底；诊断页会显示卡在第几级 |
| 改了代码但没生效 | ① assets 是否同步 ② 浏览器里 SW 缓存（`sw.js` 已改网络优先） |
| 按钮点了没反应 | `python tools/lint-actions.py`（检查 data-act 与函数定义） |
| 教务抓不到 | AdapterActivity 的「诊断」/ EduLoginActivity 的「诊断」，看 token、接口条数 |
| 课表位置错乱 | 检查 `periods` 是否 5 大节、`classTime` 解析是否按 5 位切 |
| 周次不对 | `settings.termStart` 是否为 `2026-09-07`、`termStartSet` 是否为 true |

## 九、踩过的坑（留给下一个 AI）

1. **别在没拿到真实返回前写解析器**。这个功能因此返工 6 次。先要样本，再写代码。
2. **别用区间替换改代码**。多次因为 `s[a:b]` 区间过宽，把相邻方法整段删掉。
   补方法时追加到类末尾，并用正则查重复定义。
3. **改完前端必须同步 assets**，否则 APK 里是旧代码。
4. **Service Worker 缓存优先会吃掉更新**，已改网络优先。
5. **WebView 方法只能在主线程调用**（`web.getUrl()` 在子线程会崩）。
6. **`WebViewClientCompat` 的 `onReceivedError` 是 final**，要兜底就用 `WebViewClient`。
7. **小程序/门户 H5 的接口字段名不可猜**，去读它的前端 bundle（webpack chunk）最快。
