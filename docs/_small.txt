# 企业微信里的教务系统，怎么把课表弄进 App

## 为什么不能像普通网站那样直接抓

企业微信工作台里的教务系统是 **OAuth 静默登录**：
`corpid + agentid + code → 用户身份`。`code` 由企业微信在打开页面时当场签发，一次性、几十秒失效，
外部应用既拿不到 `corpid/secret`，也拿不到那个 `code`。所以"填个网址就自动同步"这条路在企业微信里走不通。

手机上的企业微信也没有开发者工具，看不到请求。

下面三条路，按"今天就能用"到"以后能自动"排序。

---

## 路线 1：粘贴导入（今天就能用，零配置）

1. **手机**：企业微信 → 工作台 → 教务系统 → 课表页
2. 长按页面空白处 → 全选 → 复制（或先"发送到电脑"再在电脑上复制）
3. 打开课表助手 → 右上角 **导入** → 粘贴 → 解析

App 的表解析会自己认星期列、节次、周次（`1-16周`、`2-16双周` 都认）、上课地点与教师。
解析完先给你看识别结果，确认没问题才写入。

> 如果教务系统有 **导出 Excel / 导出日历(.ics)** 的按钮，优先用它，比复制粘贴准得多。

---

## 路线 2：电脑抓包拿接口（之后全自动）

企业微信 PC 端是普通桌面程序，它的 H5 走 Windows 系统证书，所以 mitmproxy 能抓。

### 步骤

```bash
# 1. 装 mitmproxy（本机已有 Python 3.10）
pip install mitmproxy

# 2. 启动，默认监听 8080
mitmweb --listen-port 8080
```

3. Windows：设置 → 网络和 Internet → 代理 → 手动设置代理 `127.0.0.1:8080`
4. 浏览器打开 `http://mitm.it` → 下载 Windows 证书 → 安装到 **受信任的根证书颁发机构**
   （双击 .cer → 安装证书 → 本地计算机 → 受信任的根证书颁发机构）
5. 打开企业微信 → 工作台 → 教务系统 → 课表页，切一下周次
6. mitmweb 界面里筛 `application/json`，找返回课表数据的那个 XHR
7. 右键该请求 → **Copy as cURL**，发我

拿到这个 cURL 我就能：

- 在 `server.mjs` 里加一个数据源适配器（把教务系统的 JSON 映射成课程/时段/周次）
- 你在 App 里点一下就同步，不用再复制粘贴
- 顺便把"未交作业""考试安排"一起接进来（如果同一个系统里有）

### 注意事项

- 企业微信可能升级后换接口，适配器要跟着改；抓包得到的 `Cookie`/`token` 有时效，过期要重抓
- 抓到的 Cookie 只写进你电脑的 `data/` 目录，不上传
- 有些学校教务系统的接口还带签名（`sign`/`timestamp`），那种要额外写签名逻辑，也能做

---

## 路线 3：让教务系统给你一个能外部打开的链接

部分学校支持"课表分享/订阅"。如果教务系统里有：

- `导出为日历订阅（webcal://…）` → 直接把链接给我，App 定时拉 `.ics` 就行
- `生成课表分享链接` → 同上
