# 课序 KeXu 0.7.46 / 0.7.47

## 0.7.46
- 修：下载面板提示「有新版」，顶栏却不出现提示
  - 根本原因是把「没有新版」也缓存了 6 小时，发版后 App 仍以为是最新
  - 现在只缓存「确实有新版」，且 1 小时过期
- 更新检测优先读仓库根目录的 `VERSION` 纯文本（比 GitHub API 快，也不容易被限流）
- 下载面板查到新版时，顶栏提示同步亮起（两处共用一份结果）

## 0.7.47
- 版本号对齐仓库 `VERSION` = 0.7.47
- 课表：周六周日支持（7 列等比塞满、导入自动开启周末列）
- 学习通：不再按课表过滤课程（军事理论那类要交作业的课会保留），改为每门课手动「隐藏 / 恢复」
- 学习通：没有任何要刷内容的课程，进度条按 100% 显示
- 设置：删掉「语言」「作息时间」两块；「更多」提到最上面
- 首启弹窗：讲清导入课表 / 学习通登录 / 反馈；微信卡片用校园墙头像，QQ 卡片用课序图标
  - 「此后不再提醒」只对当前版本有效，装新版本会再弹一次
- 图标：方案D 时间轴（深墨底 + 竖向时间轴 + 四根彩色课条），自适应前景收在 66% 安全区
- 教务：学号登录（密码默认同学号），登录后自动抓课表 / 考试 / 成绩
  - 成绩接口用页面真实参数 `pageNum/pageSize + sfxsbcxq=1`，返回 JSON
  - 考试接口带 `xnxqid=学期`

## 安装
下载 `KeXu-0.7.47.apk` 覆盖安装即可，数据不会丢（versionCode 181）。

## 已知
- `raw.githubusercontent.com` 国内偶尔被拦，届时顶栏不提示，可到「设置 → 更多」点状态行强制重查
- 学习通总进度依赖学校页面口径，个别课程可能显示 0%，可手动隐藏
